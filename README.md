# KHighPass2

Recursive Hann-style waveform mass highpass.

KHighPass2 removes low-frequency “mass” by subtracting a smoothly diffused version of the waveform from the original signal. Instead of traditional EQ topology, the processor uses cascaded Hann/binomial-style smoothing stages to create a softer, more natural highpass character with reduced combing and less harsh phase feel.

Features:

* Smooth waveform-mass subtraction
* Recursive Hann/binomial-inspired filtering
* Gentle spectral thinning instead of aggressive EQ
* Adjustable cutoff behaviour
* Natural transient openness
* Low CPU design

Good on:

* Mix bus cleanup
* Removing mud without sounding clinical
* Opening dense instruments
* Bass management with softer edges
* Air and motion enhancement before compression
